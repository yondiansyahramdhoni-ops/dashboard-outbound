Sumber Data Rute & Slot Time (Link CSV Google Sheet)

Format sumber data KPI menggunakan Google Sheet CSV. Golden Hour: Tanggal, Destinasi, INBOUND, PACKED, OUTBOUND, INDIKATOR, KETERANGAN ISSUE (INBOUND/PACKED/OUTBOUND diisi persen, boleh kosong kalau tidak ada datanya untuk baris itu; INDIKATOR diisi manual: Aman / Perhatian / Bermasalah). Productivity: Tanggal, Target Prod, Total MP, Total Gap Outbound, Gap Mulai, Gap Akhir, Keterangan.

Kolom yang dibaca dari Google Sheet: No Gate, Rute / Tujuan, Slot Time (isi tiap jam dipisah koma, contoh: 04:00,12:00,23:15).

Cara ambil link: buka Google Sheets → File → Share → Publish to web → pilih sheet Rute & Slot → format CSV → Publish → salin link ke sini.

Setelah disimpan, link ini otomatis dipakai di semua perangkat yang membuka dashboard ini — tim tinggal edit sheet, dan halaman ini akan ikut memperbarui slot time secara otomatis setiap 2 menit (atau tekan "Refresh Jadwal" untuk langsung memperbarui).
